Questions

How is this different from cloud tools like Scribe?

Cloud tools upload what you capture so their servers can process it. Stepwise does all of its work on your Mac and uploads nothing. It also keeps the screen recording next to the screenshots, so you can jump to the moment behind any step.

How does the license work?

Buy Pro and you get a key by email. Paste it into Settings, License. Stepwise checks it with Polar, our payment partner, and re-checks it every few days while you are online. In between, it keeps working offline for up to 30 days.

Why does it need Screen Recording and Accessibility?

Screen Recording is how any Mac app is allowed to see the screen: it produces the video and each screenshot. Accessibility lets Stepwise read the name of the button or menu you clicked so it can write the caption. Without it, steps get generic captions you can edit by hand.

Where are my guides stored?

In ~/Library/Application Support/Stepwise, one folder per guide, holding the video, the screenshots and a small JSON file. Settings has a button that opens it in Finder.

Can I trust the download?

The app is signed with an Apple Developer ID and notarized by Apple, so it opens normally under Gatekeeper. The SHA-256 of the file is in the footer. Check it with shasum -a 256 Stepwise-0.1.1.dmg.

What happens if I stop paying?

Nothing is deleted. Your guides and videos stay on your Mac. Pro features switch off and the Free limits apply to new guides.

How does it update?

Stepwise checks this website once a day for a newer version and, if there is one, offers to install it. Every update is signed with our key and the app refuses anything that isn’t, so only a build from us can replace it. You can switch the daily check off in Settings and use “Check for Updates…” from the Stepwise menu instead.

Does it record audio or my camera?

No. It records the screen only, and only while you are recording.
